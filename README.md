# Vi — استوديو التوليد بالذكاء الاصطناعي 🎨🎬

تطبيق ويب لتوليد **الصور** و**الفيديو** من وصف نصي بالعربية، مبني على Next.js 16 مع حفظ كامل لسجل الأعمال في قاعدة بيانات **Turso (libSQL)** والتوليد عبر منصة **kie.ai**.

## المزايا

- 🖼️ توليد الصور بالنموذج `gpt-image-2-6/flare-text-to-image`
- 🎬 توليد الفيديو بالنموذج `grok-imagine-video-1-5-preview` (مع صوت تلقائي ومدة 1–15 ثانية)
- 💬 **شات جي بي تي مدمج**: مساعد محادثة يصيغ لك الأوصاف ويولّد الصور والفيديو مباشرة من داخل المحادثة، مع إمكانية الربط بمفتاح OpenAI (ChatGPT) الخاص بك من الإعدادات
- 🤖 **تحكم من ChatGPT الخارجي (Custom GPT)**: مخطط OpenAPI جاهز على `/api/openapi.json` يسمح لـ Custom GPT في ChatGPT بالتحكم في التطبيق بالكامل (توليد، متابعة، سجل، حذف) عبر الـ Actions
- 🌓 واجهة عربية RTL بتصميم داكن أنيق، متوافقة مع الجوال والحاسوب
- 🗂️ سجل كامل لكل عمليات التوليد مع حالة مباشرة (انتظار → توليد → اكتمال)
- ⬇️ تحميل النتائج ونسخ الروابط وحذف العناصر من السجل
- 🗄️ قاعدة بيانات Turso تعمل محليًا وعلى Vercel دون أي إعداد إضافي (الجداول تُنشأ تلقائيًا)

## البنية التقنية

| الطبقة | التقنية |
| --- | --- |
| الواجهة | Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui |
| قاعدة البيانات | Turso (libSQL) عبر `@libsql/client` |
| التوليد | kie.ai Jobs API (`createTask` / `recordInfo`) |
| النشر | Vercel |

## متغيرات البيئة

| المتغير | إلزامي | الوصف |
| --- | --- | --- |
| `TURSO_DATABASE_URL` | نعم | رابط قاعدة البيانات `libsql://...` |
| `TURSO_AUTH_TOKEN` | نعم | توكن قاعدة البيانات من لوحة Turso |
| `KIE_API_KEY` | نعم | مفتاح API من [kie.ai](https://kie.ai/api-key) |
| `KIE_IMAGE_MODEL` | لا | نموذج الصور (الافتراضي `gpt-image-2-6/flare-text-to-image`) |
| `KIE_VIDEO_MODEL` | لا | نموذج الفيديو (الافتراضي `grok-imagine-video-1-5-preview`) |
| `KIE_CHAT_MODEL` | لا | نموذج المحادثة (الافتراضي `kimi-k3-1-pro`) |
| `OPENAI_API_KEY` | لا | لربط المحادثة بمفتاح OpenAI/ChatGPT على مستوى الخادم |
| `OPENAI_MODEL` | لا | نموذج OpenAI (الافتراضي `gpt-4o-mini`) |

> ملاحظة: يمكن لكل مستخدم أيضًا إدخال مفتاح OpenAI الخاص به من إعدادات المحادثة داخل التطبيق — يُحفظ في متصفحه فقط.

انسخ `.env.example` إلى `.env` واملأ القيم للتشغيل محليًا.

## التشغيل محليًا

```bash
bun install
bun run dev
```

ثم افتح `http://localhost:3000`.

## النشر على Vercel

1. ارفع الكود إلى مستودع GitHub (مستودع `Vi`).
2. من [vercel.com/new](https://vercel.com/new) اختر **Import** للمستودع.
3. في خطوة **Environment Variables** أضف المتغيرات الثلاثة الإلزامية:
   - `TURSO_DATABASE_URL`
   - `TURSO_AUTH_TOKEN`
   - `KIE_API_KEY`
4. اضغط **Deploy** — لا يحتاج المشروع أي إعداد آخر (Vercel يتعرّف على Next.js تلقائيًا).

## الربط مع ChatGPT (Custom GPT) 🤖

يمكنك أن تتحكم أنت بأمر شات جي بي تي ليعمل تطبيقك نيابة عنه — ينشئ الصور والفيديو عبر نموذجك ويعيد الروابط إليك داخل المحادثة:

1. انشر التطبيق على Vercel (شات جي بي تي يحتاج رابطًا عامًا).
2. من تبويب **«ربط ChatGPT»** داخل التطبيق انسخ رابط المخطط: `https://<دومينك>/api/openapi.json`
3. افتح chatgpt.com → استكشاف GPTs → إنشاء → تبويب **Configure** → **Actions** → **Import from URL** والصق الرابط.
4. في خانة **Privacy Policy URL** ضع: `https://<دومينك>/privacy`
5. انسخ نص التعليمات الجاهز من نفس التبويب والصقه في **Instructions** ثم احفظ.
6. جرّب: «ولّد لي صورة قطة فضائية يشرب قهوة» — سينشئ المهمة في تطبيقك ويتابعها ويعيد رابط النتيجة.

> المخطط يعرّف 4 عمليات: `createGeneration` و`getGeneration` (يدعم `?wait=8` لتقليل الاستدعاءات) و`listGenerations` و`deleteGeneration`. رابط الخادم يُبنى تلقائيًا من دومين الاستيراد فلا يحتاج أي تعديل يدوي.

## مسارات API

| المسار | الوصف |
| --- | --- |
| `POST /api/generate` | إنشاء مهمة توليد (صورة أو فيديو) |
| `GET /api/generations` | جلب آخر 60 عملية توليد |
| `GET /api/generations/[id]` | حالة عنصر معيّن (يُحدّث الحالة من kie.ai) — يدعم `?wait=8` للانتظار الدوري |
| `DELETE /api/generations/[id]` | حذف عنصر من السجل |
| `GET /api/openapi.json` | مخطط OpenAPI 3.1 لاستيراده في ChatGPT كـ Custom GPT Action |
| `GET /privacy` | سياسة الخصوصية (مطلوبة عند إنشاء الـ Custom GPT) |
| `POST /api/chat` | إرسال رسالة لمساعد شات جي بي تي |
| `GET /api/chat` | سجل المحادثة |
| `DELETE /api/chat` | مسح سجل المحادثة |
| `GET /api` | فحص صحة الخدمة |
