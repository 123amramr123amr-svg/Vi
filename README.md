# Vi — استوديو التوليد بالذكاء الاصطناعي 🎨🎬

تطبيق ويب لتوليد **الصور** و**الفيديو** من وصف نصي بالعربية، مبني على Next.js 16 مع حفظ كامل لسجل الأعمال في قاعدة بيانات **Turso (libSQL)** والتوليد عبر منصة **kie.ai**.

## المزايا

- 🖼️ توليد الصور بالنموذج `gpt-image-2-6/flare-text-to-image`
- 🎬 توليد الفيديو بالنموذج `grok-imagine-video-1-5-preview` (مع صوت تلقائي ومدة 1–15 ثانية)
- 🔗 **تكملة الفيديو (سلسلة أجزاء)**: زر «تكملة الفيديو (جزء تاني)» على أي فيديو مكتمل — ارفع صور الجزء الجديد فيحركها النموذج (image-to-video)، أو استخدم التكملة التلقائية الرسمية `grok-imagine/extend` التي تكمل نفس الفيديو من نهايته — وكررها لأجزاء 2 و3 و4… لتبني فيديو طويل من مقاطع 15 ثانية
- 💬 **شات جي بي تي مدمج**: مساعد محادثة يصيغ لك الأوصاف ويولّد الصور والفيديو مباشرة من داخل المحادثة، مع إمكانية الربط بمفتاح OpenAI (ChatGPT) الخاص بك من الإعدادات
- 🤖 **تحكم من ChatGPT الخارجي (Custom GPT)**: مخطط OpenAPI جاهز على `/api/openapi.json` يسمح لـ Custom GPT في ChatGPT بالتحكم في التطبيق بالكامل (توليد، متابعة، نشر، سجل، حذف) عبر الـ Actions
- 🔌 **دعم MCP (Model Context Protocol)**: خادم MCP جاهز على `/mcp` يتيح لأي عميل يدعم البروتوكول — Claude وCursor وWindsurf وCodex CLI وغيرها — التحكم الكامل في التطبيق بأدوات قياسية (توليد، متابعة، نشر، حذف، أوتوبايلوت)
- 🚀 **نشر تلقائي (أوتوبايلوت)**: الموقع ينشر فيديوهات وصور جديدة في معرض عام تلقائيًا دون تدخل — كل يوم على Vercel Cron، أو بزر واحد، أو بأمر لشات جي بي تي، مع قائمة مواضيع تدور تلقائيًا
- 🌓 واجهة عربية RTL بتصميم داكن أنيق، متوافقة مع الجوال والحاسوب
- 🗂️ سجل كامل لكل عمليات التوليد مع حالة مباشرة (انتظار → توليد → اكتمال)
- ⬇️ تحميل النتائج ونسخ الروابط وحذف العناصر من السجل
- 🗄️ قاعدة بيانات Turso تعمل محليًا وعلى Vercel دون أي إعداد إضافي (الجداول تُنشأ تلقائيًا)

| `AUTOPILOT_TOKEN` | لا | حماية مسار الأوتوبايلوت — اتركه فارغًا ليعمل مفتوحًا |
| `CRON_SECRET` | لا | يرسله Vercel Cron تلقائيًا للتوقيع — يُقبل أيضًا كتوكن للأوتوبايلوت |
| `AUTOPILOT_TOPICS` | لا | مواضيع النشر التلقائي المخصصة مفصولة بـ `\|` |
| `MCP_API_KEY` | لا | يحمي خادم MCP بترويسة `Authorization: Bearer <key>` — اتركه فارغًا ليعمل مفتوحًا |

> ملاحظة: يمكن لكل مستخدم أيضًا إدخال مفتاح OpenAI الخاص به من إعدادات المحادثة داخل التطبيق — يُحفظ في متصفحه فقط.

انسخ `.env.example` إلى `.env` واملأ القيم للتشغيل محليًا.

```bash
bun install

```

ثم افتح `http://localhost:3000`.

## النشر على Vercel

1. ارفع الكود إلى مستودع GitHub (مستودع `Vi`).
2. من [vercel.com/new](https://vercel.com/new) اختر **Import** للمستودع.
3. في خطوة **Environment Variables** أضف المتغيرات الثلاثة الإلزامية:
   - `TURSO_DATABASE_URL`
   - `TURSO_AUTH_TOKEN`
   - `KIE_API_KEY`
4. اضغط **Deploy** — لا يحتاج المشروع أي إعداد آخر (Vercel يتعرّف على Next.js تلقائيًا).

## تكملة الفيديو — سلسلة أجزاء 🔗

كل فيديو مكتمل يظهر عليه زر **«تكملة الفيديو (جزء تاني)»** — بضغطة واحدة تتحول لوحة الإنشاء لوضع التكملة، وترث نسبة الأبعاد والدقة والمدة من الجزء السابق، ويرتبط الجزء الجديد بالأصل ويظهر بشارة «جزء 2» ثم «جزء 3» وهكذا:

1. **من صور الجزء الجديد (الافتراضي)**: ارفع حتى 3 صور (PNG/JPG/WebP حتى 4 ميجا عبر `POST /api/uploads`) واكتب وصف الجزء — النموذج يحرك الصور كالمشهد التالي (image-to-video) ويتناسق مع الفيديو الأصلي.
2. **تكملة تلقائية من النهاية**: دون صور — يستدعي نموذج التكملة الرسمي `grok-imagine/extend` بمعرّف مهمة الفيديو الأصلي فيُكمل نفس الفيديو من نهايته بدقة المصدر (التكلفة على الثواني المضافة فقط).

نفس القدرة متاحة لـ ChatGPT (حقولا `parentId` و`imageUrls` و`extend` في createGeneration) ولأدوات MCP (أداة `continue_video`) — فأي وكيل ذكاء اصطناعي يستطيع بناء سلاسل فيديو طويلة تلقائيًا. للدمج النهائي للأجزاء في ملف واحد استخدم أي أداة دمج فيديو بعد تحميل الأجزاء بالترتيب.

## الربط مع ChatGPT (Custom GPT) 🤖

يمكنك أن تتحكم أنت بأمر شات جي بي تي ليعمل تطبيقك نيابة عنه — ينشئ الصور والفيديو عبر نموذجك ويعيد الروابط إليك داخل المحادثة:

1. انشر التطبيق على Vercel (شات جي بي تي يحتاج رابطًا عامًا).
2. من تبويب **«ربط ChatGPT»** داخل التطبيق انسخ رابط المخطط: `https://<دومينك>/api/openapi.json`
3. افتح chatgpt.com → استكشاف GPTs → إنشاء → تبويب **Configure** → **Actions** → **Import from URL** والصق الرابط.
4. في خانة **Privacy Policy URL** ضع: `https://<دومينك>/privacy`
5. انسخ نص التعليمات الجاهز من نفس التبويب والصقه في **Instructions** ثم احفظ.
6. جرّب: «ولّد لي صورة قطة فضائية يشرب قهوة» — سينشئ المهمة في تطبيقك ويتابعها ويعيد رابط النتيجة.

> المخطط يعرّف 8 عمليات: `createGeneration` و`getGeneration` (يدعم `?wait=8` لتقليل الاستدعاءات) و`publishGeneration` و`unpublishGeneration` و`listPublishedWorks` و`runAutopilot` و`listGenerations` و`deleteGeneration`. رابط الخادم يُبنى تلقائيًا من دومين الاستيراد فلا يحتاج أي تعديل يدوي.

## الاتصال عبر MCP (Claude، Cursor، وغيرها) 🔌

إلى جانب Actions، يوفّر التطبيق خادم **MCP (Model Context Protocol)** قياسيًا على المسار `/mcp` (نوع النقل: Streamable HTTP، وضع عديم الحالة) يتيح لأي وكيل ذكاء اصطناعي يدعم البروتوكول التحكم الكامل في الموقع:

| الأداة | الوظيفة |
| --- | --- |
| `generate_image` | توليد صورة (مع `wait_seconds` لإرجاع النتيجة في نفس الطلب) |
| `generate_video` | توليد فيديو (مدة 1–15 ث، دقة، صوت، صور اختيارية image-to-video) |
| `continue_video` | تكملة فيديو مكتمل كجزء جديد: من صور (`mode=images`) أو تمديد تلقائي (`mode=extend`) |
| `get_generation` | متابعة حالة المهمة وجلب روابط النتيجة |
| `list_generations` | سجل التوليد الكامل |
| `list_published` | ما هو منشور في المعرض العام |
| `publish_generation` | نشر/إخفاء عمل في المعرض |
| `delete_generation` | حذف عنصر من السجل |
| `run_autopilot` | خطوة النشر التلقائي: نشر المكتمل + إنشاء فيديو جديد — هكذا يبقى الموقع ينشر دون تدخل بشري |

**الربط:** من تبويب **«MCP»** داخل التطبيق انسخ رابط الخادم `https://<دومينك>/mcp` والإعدادات الجاهزة، ثم أضفه في عميلك:

```json
{
  "mcpServers": {
    "vi-ai-studio": {
      "url": "https://<دومينك>/mcp"
    }
  }
}
```

> لحماية الخادم ضع `MCP_API_KEY` في متغيرات البيئة وأضف الترويسة `Authorization: Bearer <المفتاح>` في إعدادات العميل. بدونه يبقى الرابط مفتوحًا لأي شخص يعرف دومين موقعك.

## النشر التلقائي والمعرض العام 🚀

الموقع ينشر من تلقاء نفسه دون أي تدخل منك، بثلاث قنوات:

1. **Vercel Cron (يوميًا تلقائيًا)**: ملف `vercel.json` مجدول على استدعاء `/api/autopilot/run` كل يوم 9 صباحًا UTC — ينشر الأعمال المكتملة في المعرض ثم ينشئ فيديو عموديًا جديدًا (9:16 بنمط السوشيال ميديا) من قائمة مواضيع تدور تلقائيًا، ويُنشر وحده عند اكتماله في الزيارة التالية.
2. **شات جي بي تي**: قل للـ Custom GPT «انشر فيديوهات جديدة على الموقع» — يستدعي runAutopilot ويتابع حتى النشر.
3. **يدويًا**: تبويب «النشر التلقائي» داخل التطبيق (زر تشغيل + إدارة المعرض)، أو زر الكرة الأرضية على أي عمل مكتمل في السجل.

المعرض العام للزوار على `/gallery` — كل ما يُنشر يظهر فيه فورًا مع شارة «نشر تلقائي» لأعمال الأوتوبايلوت. لتخصيص مواضيع الفيديو ضع `AUTOPILOT_TOPICS` في متغيرات البيئة (أوصاف إنجليزية مفصولة بـ `\|`). ولحماية مسار الأوتوبايلوت من الغرباء ضع `AUTOPILOT_TOKEN` (ثم أدخله من زر «توكن الحماية» في التطبيق، وفي ChatGPT أضفه كترويسة `x-autopilot-token`).

## مسارات API

| المسار | الوصف |
| --- | --- |
| `POST /api/generate` | إنشاء مهمة توليد (صورة أو فيديو) — ويدعم تكملة الفيديو عبر `parentId`/`imageUrls`/`extend` |
| `POST /api/uploads` | رفع صورة (multipart، حقل `file` — حتى 4 ميجا PNG/JPG/WebP) لإستخدامها في تحريك الفيديو |
| `GET /api/uploads/[id]` | خدمة صورة مرفوعة برابط عام يستخدمه مزوّد التوليد |
| `GET /api/generations` | جلب آخر 60 عملية توليد |
| `GET /api/generations/[id]` | حالة عنصر معيّن (يُحدّث الحالة من kie.ai) — يدعم `?wait=8` للانتظار الدوري |
| `DELETE /api/generations/[id]` | حذف عنصر من السجل |
| `GET /api/openapi.json` | مخطط OpenAPI 3.1 لاستيراده في ChatGPT كـ Custom GPT Action |
| `GET /privacy` | سياسة الخصوصية (مطلوبة عند إنشاء الـ Custom GPT) |
| `PUT /api/generations/[id]/publish` | نشر العمل المكتمل في المعرض العام `/gallery` |
| `DELETE /api/generations/[id]/publish` | إلغاء النشر من المعرض (يبقى في السجل) |
| `GET /api/published` | الأعمال المنشورة حاليًا (للزوار وChatGPT) |
| `GET/POST /api/autopilot/run` | خطوة الأوتوبايلوت: نشر المكتمل + إنشاء مهمة جديدة (كرون يومي) |
| `POST /mcp` | خادم MCP (JSON-RPC 2.0 / Streamable HTTP): initialize، tools/list، tools/call |
| `GET /gallery` | المعرض العام للزوار |
| `POST /api/chat` | إرسال رسالة لمساعد شات جي بي تي |
| `GET /api/chat` | سجل المحادثة |
| `DELETE /api/chat` | مسح سجل المحادثة |
| `GET /api` | فحص صحة الخدمة |
